# examples/

Example implementations demonstrating how to build on the Wisdum platform: API consumers, plugin implementations, workflow automations, and integration patterns.

## Conventions

- One directory per example, each runnable in isolation with its own README.
- Examples target the public platform surface only — versioned APIs, events, and provider contracts. If an example needs internal access, that's a gap in the platform API worth filing.
- Examples are kept working: they compile and run against the current platform in CI (once CI exists).
